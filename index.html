OUR FIRST TOOL

Save Compatibility Tester

Check whether historical player saves still load after your game changes - before you ship the update.

Versioned regression tests

Run saves from every released version against your current loading and migration code.

Actionable failures

See the affected file, field, expected value, actual value, and a suggested fix.

PlayerPrefs snapshots

Capture and validate required PlayerPrefs keys, types, numeric ranges, and non-empty strings.

Reports and CI

Export HTML or JSON reports and fail automated release checks when compatibility breaks.

QUICK START

Install and run in minutes

  1. 1
    Import

    In Unity, open Assets > Import Package > Custom Package and import all files.

  2. 2
    Open

    Select Tools > Save Compatibility Tester.

  3. 3
    Try the demo

    Choose Load Demo, then run the three compatibility tests. Two passes and one intentional failure are expected.

  4. 4
    Connect your game

    Create a PlayerPrefs profile or generate an adapter for your existing save loader.

Use anonymized fixtures only. Never store player names, emails, account tokens, credentials, or other personal information.
